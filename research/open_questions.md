# Open research questions

TLA is intentionally published before a single implementation is treated as canonical.

## AER

- How should a system determine that evidence is sufficient?
- Which uncertainty measures are useful in territorial decision contexts?
- How can routing overhead remain lower than the work it avoids?
- When should model calibration, abstention, source agreement or human validation be used?
- Which simple routing policies outperform uniform RAG+LLM workflows?

## CAER

- Which contextual variables are most useful for deciding Reuse / Adapt / Re-experiment?
- How can context comparison remain interpretable?
- When is a causal graph necessary?
- How should hidden or unobserved contextual factors be represented?
- Can targeted micro-experiments test only the contextual difference blocking transfer?

## Memory

- Which tasks benefit from compiled Wiki, GraphRAG, knowledge graph or hierarchical memory?
- How should knowledge be versioned and invalidated?
- How should negative and null results be represented?
- How should multi-actor and multi-territory experiences be represented?
- How can experience records align with W3C PROV and RO-Crate?

## Governance

- Which decisions may be automated, assisted or require explicit human authorization?
- How should contestability and public accountability be represented technically?
- How should sensitive experiences be shared without disclosing protected information?

## Evaluation

A first useful benchmark should remain small. It should compare simple alternatives on a bounded territorial decision task before any claim of generality is made.
