# TLA pre-publication checklist

The repository is intentionally private during manuscript preparation.

## Before public release

- [x] Repository created
- [x] Initial README
- [x] Core learning-cycle diagram
- [x] System-architecture documentation
- [x] Core design principles
- [x] Decision-provenance model
- [x] Evaluation framework
- [x] Illustrative Martinique case
- [x] Contribution guidelines
- [ ] Final French manuscript validated by the author
- [ ] Definitive English manuscript produced
- [ ] Bibliography checked reference by reference
- [ ] Final figures and captions checked
- [ ] AI-use disclosure finalized
- [ ] Author metadata checked
- [ ] License selected
- [ ] CITATION.cff finalized
- [ ] Final PDF added
- [ ] Repository visibility changed from Private to Public
- [ ] Version 1.0 release created
- [ ] DOI archive created/linked (e.g. Zenodo)
- [ ] DOI added to README and citation metadata

## Release principle

No public release should imply empirical validation that has not occurred. The first release should be described as a research preprint / technical paper and open architecture.
