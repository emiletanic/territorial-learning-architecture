# Release notes — v0.1.0

## TLA — Territorial Learning Architecture

This first open research release introduces a reference architecture for AI-assisted territorial learning.

### Core design patterns

- **AER — Adaptive Evidence Routing**  
  Route a decision toward the least costly reliable evidence source proportionate to uncertainty, risk and reversibility.

- **CAER — Context-Aware Experience Reuse**  
  Reuse prior experience only after comparing source and target contexts; choose **Reuse**, **Adapt**, or **Re-experiment**.

### Architecture

The release also defines:

- Evidence Memory;
- Compiled Knowledge Memory;
- Experiential Memory;
- anti-drift rules;
- decision traceability;
- a minimal experience record;
- an open research agenda.

### Scientific status

This is an **open research architecture / position paper**. It does not claim that AER is an optimal routing algorithm, that CAER automatically demonstrates causal transportability, or that the architecture has already been empirically validated.
